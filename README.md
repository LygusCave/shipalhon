# SHIPALHON 
* Shipalhon (白파란红) is a CJK to russian translitiration systems translator
* It's created for translators, to hlep them, if they're forget/don't know specific system.
* There is CN to Palladius' system translator, created with using a ['pinyin-pro'](https://github.com/zh-lx/pinyin-pro). And JP to Polivanov's system translator, created via ['kuroshiro'](https://github.com/hexenq/kuroshiro) and ['kuroshiro-analyzer-kuromoji'](https://github.com/hexenq/kuroshiro-analyzer-kuromoji). And KR to Kontzevich's (russian practic transcription) created with using ['es-hangul'](https://github.com/toss/es-hangul).
* Maybe I'll add other langs in futere.
